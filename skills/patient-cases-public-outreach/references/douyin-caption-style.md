# 抖音医疗求助文案模板

## 模板（4 段式，硬约束）

```text
🚨 海外求医求助

我们是 China Hospitals Guide（海外医疗协调方）。
手上有个 {年龄} 海外患者，{国籍}，住{国家}，
{时长} 求医无门：
· {病名1}（{医学名}）
· {病名2}（{医学名}）
体重从 {X kg} 掉到 {Y kg}，已无法工作学习。

我们联系了 {N} 家医院都被拒：
❌ {医院1} —— {原因}
❌ {医院2} —— {原因}
❌ {医院3} —— {原因}
统一答复：本人到场 → 现场审 → 排队治疗。

可她飞一次中国要 3 万，没确诊谁也不敢盲飞。

🙏 我们只想要一个机会：
1. {诉求1}
2. {诉求2}
3. {诉求3}

有医院 / 有医生 / 有渠道，评论区扣 1 留个言。
我私信你微信号，完整病历影像可以发过去。

#海外求医 #{病名tag} #{科室tag} #{病名tag2} #医疗求助
```

## 段落职责分配

| 段 | 职责 | 字数上限 | 强制元素 |
|---|---|---|---|
| 1 钩子 | 抓住医生刷到的 1.5 秒 | ≤ 50 字 | emoji 🚨 + 一句定位 |
| 2 患者身份 | 谁、什么病、严重程度 | ≤ 80 字 | 年龄 + 国别 + 关键数字 |
| 3 困境 | 已尽力、为什么还是不行 | ≤ 100 字 | 3 家医院 + ❌ + 一句总结 |
| 4 诉求 | 我们到底要什么 | ≤ 80 字 | 编号 1/2/3 + 联系方式 |

## 禁用词 → 替换词表

| 禁用 | 替换 | 原因 |
|---|---|---|
| 100% 治好 | 擅长 | 抖音审核拦截 |
| 保证 / 包治 | 可以判断 | 同上 |
| 三甲都不要 | 答复统一 | 避免贬低 |
| 医生都不行 | 答复统一 | 同上 |
| 根治 | 治疗 / 处理 | 抖音医疗限流 |

## 隐私边界（每次都问伟烨 3 个事）

1. 患者姓名公开 vs 匿名（"一位 27 岁荷兰姑娘" vs 完全匿名）
2. 国别/身份公开（涉及对患者安全的判断，军事医院对外籍有限制）
3. 已联系医院是否点名（3 家以内 OK，超过会变成"打广告"）

## 发布小提示（每次附在最后）

- 发布后**立刻在评论区自己置顶**一条：📌 "资料齐全，海外病历中英双语 + 完整 DICOM 影像，评论区扣 1 私信微信号"。置顶评论拉高互动率。
- 抖音医疗类内容容易被限流，**早上 8-10 点发**算法起步更快。
- **不要**在文案里出现"100%" "保证治好"——会被审核拦截。
- 前 6 小时是关键，发布后自己多在评论区互动（回复每一条留言）拉高流量池。

## 长文拆段（伟烨 2026-07-08 拍板）

如果素材文案超过 600 字，**必须拆 Part 1/2 贴出**，分隔符：

```
--- Part 1 / 2 ---
[前一半]
--- Part 2 / 2 ---
[后一半]
```

拆在**段落中间**，不切句子。

## 触发器：纯文本发布模式

伟烨说"**直接发我 / 我直接转发 / 复制用**"→

- 文案正文**禁止**任何附注（⚠️ / 要不要改 / 数字确认 / 钩选话术）
- 所有沟通放到飞书对话单独发
- 不要问"要不要再出一版"——他转不出去
