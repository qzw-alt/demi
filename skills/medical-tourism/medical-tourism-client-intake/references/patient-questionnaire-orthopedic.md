# 骨科患者咨询标准问题清单

来源：2026-07-26 膝盖置换客户首次接洽。**这是一次"问一下客户基本信息"的简单任务触发**——伟烨反馈："我需要你帮我去问一些问题，个人问题。姓名、年龄、居住地、来中国哪个城市之类，都是业务范围内基本询问。"

**设计原则**：

- **直接列问题**，不替伟烨决定"要不要问" / "用微信还是邮件" / "要不要 case sharing"
- **14 个点** 是上限，不要更多（客户耐心阈值）
- **拆 4 段**：基本信息 / 病情 / 期望 / 特殊情况
- **翻译链路**：中文 14 点 → 客户回答案 → agent 翻译成英文给医院对接用

## 14 点核心问题

### 一、基本信息（4 件）

1. **姓名**（微信 / 护照名，方便对接医院记录）
2. **年龄**
3. **居住地**（国 + 城市）
4. **国籍**

### 二、病情（4 件）

5. **膝关节问题多久了？**（确诊时间 / 病因 / 退化 / 意外 / 其他）
6. **之前做过什么检查？**（X 光 / MRI / 血液报告）
7. **现在最影响生活的症状？**（疼痛 / 不能走远 / 上下楼梯 / 睡眠）
8. **本国医生建议怎么处理？**（手术 / 保守 / 换关节 / 其他）

### 三、期望（4 件）

9. **为什么想来中国？**（费用 / 技术 / 等待时间 / 朋友推荐）
10. **有想来中国哪个城市？**（北京 / 上海 / 广州 / 没有偏好听你推荐）
11. **打算什么时候来？**（立刻 / 几周内 / 几月内 / 只是先问）
12. **预算大概多少？**（含手术 + 住院 + 机票 + 停留）

### 四、特殊情况（2 件）

13. **有没有慢性病？**（糖尿病 / 高血压 / 心脏 / 服药中）
14. **有没有来过中国？**（签证 / 家人同行 / 语言 / 陪同）

## 微信发送格式（中文 · 给客户看）

```
第一段：
X 先生/女士好，我是 Weiye（China Hospitals Guide 协调负责人）。
了解到您咨询膝关节置换，为了给您更准确的医院推荐，
方便先回答几个问题吗？分几次发给我都行。

第二段（直接列 14 个问题）：

一、基本信息
1. 姓名（护照名）
2. 年龄
3. 居住地（国+城市）
4. 国籍

二、病情

6. 做过什么检查？

三、期望
```

## 翻译后给医院对接的字段映射

客户回信后，把答案映射成医院对接表：

| 客户问 | 医院对接字段 |
|---|---|
| #1 姓名 | Hospital record patient name |
| #2 年龄 | Age (手术风险评估) |
| #3-4 居住地/国籍 | Visa + 出差安排 |
| #5-8 病情 | Primary diagnosis + history |
| #9 为什么来中国 | Marketing source (网站/朋友/医生推荐) |
| #10 城市 | Preferred city |
| #11 时间 | Treatment timeline |
| #12 预算 | Budget bracket |
| #13 慢性病 | Comorbidity alert (surgical risk) |
| #14 来过中国 | Visa status, language, companion |

## 适用范围

- 膝关节置换
- 髋关节置换
- 脊柱手术（腰椎 / 颈椎）
- 运动医学（半月板 / 韧带 / 软骨修复）
- 其他骨科择期手术

**不适用于**：
- 急性创伤（车祸骨折等）—— 直接走医院急诊流程
- 神经外科 / 肿瘤 —— 走对应专属问卷
- 心血管 —— `references/patient-questionnaire.md`
