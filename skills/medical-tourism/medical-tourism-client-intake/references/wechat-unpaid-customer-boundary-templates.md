# 微信 / WhatsApp 短消息客户边界话术

> **范围**：微信 / WhatsApp / Telegram 等即时通讯工具上的"客户对话边界"
> **问题域**：与 medical-tourism-client-intake 的邮件长文不同 —— 这里客户耐心低、屏幕小、节奏快、对话天然非正式
> **触发**：客户没走流程、直接加私人号、发资料过来、问具体病情、问定价后没付款

---

## 三条核心边界规则

### 1. **微信不收款**

- 微信国内版对跨境支付有管制（个人收款额度、跨境转账限制、外汇申报）
- WeChat 国际版收款不覆盖中国大陆对公账户
- **结论**：医疗协调费 ¥49 / ¥399 不能走微信，**只用 PayPal**
- 客户问"你支持微信支付吗" → 给 PayPal 链接 + 一句解释（不要"我们不支持"冷冰冰）

### 2. **成本结构 vs 流程规定**

- ❌ **不说"流程规定"** —— 听起来官僚
- ✅ **说"成本结构"** —— 客户更容易接受：医生时间成本 + 人力协调成本 + 医院接洽成本，三块加起来不是免费能撑起的
- 把"收费"框成"启动"：付 ¥49 = 服务启动（不付 = 医生不会介入）

### 3. **不评价客户本地医生方案**

- 客户提"当地建议放化疗" / "当地建议手术" —— **不评价**
- 不评判、不对比、不说"中国更好" / "美国更好"
- 给客户中立空间："如果你已经在本地医院启动治疗，**先按当地走**，我们随时能配合"

## 微信短消息的 4 个格式规则

### 1. **每条 1-2 句，分多条发**

微信跟邮件不一样：
- 一长段 = "复制粘贴怪" / "机器人感"
- 多条短 = "人味" / "对话感"
- 客户能"消化"每条再读下一条

### 2. **不加 emoji 在正文（除非伟烨习惯）**

- 微信本身支持 emoji，但"中医保健" / "严肃病情"语境下
- 客户发来癌症资料，你回"👍👍👍" = 不尊重
- **只用 1 个 🙏** 在结尾 = 不冷漠

### 3. **不写 Markdown**

微信不是 Markdown 渲染器：
- `**bold**` 会显示成字面 `**bold**`
- `# 标题` 会显示成字面 `# 标题`
- 用纯文本 + 空行分段

### 4. **结尾明确 CTA**

每段对话**最后一条**要有可点击动作：
- "看下套餐说明" / "告诉我您大概在什么阶段" / "如果急就告诉我"

不要"我说完了你看着办" —— 微信里这种结尾 = 客户关掉对话框

## 3 段反驳预案（客户可能问）

### "¥49 包含什么 / 不包含什么？"

```
¥49 包含：病例整理 + 2-3 家医院推荐 + 全程费用预估。
不包含：医生直接沟通（那是 ¥399 协调套餐里）。
如果 ¥49 做完您觉得合适，再决定 ¥399 是否启动。
```

### "看了你网站，没付款你们也会给建议吧？"

```
网站上公开的内容是给所有人看的通用信息。
但您这种情况——具体看您的资料 + 联系具体医院 + 让医生介入——
这三件事都是要成本的，¥49 就是启动这个的成本。
```

### "我先付 ¥49 但不一定继续 ¥399"

```
完全可以。¥49 是独立服务，做完您拿到报告，自己决定下一步。
我们不会催您继续 ¥399，也不会因为您不继续就降级服务。
```

## 微信 → 英文版的转换规则

**触发**：客户是海外（英文 / 俄语 / 印尼 / 阿语），需要用对应语言版本。

**核心差异**：
- 微信 IM 节奏 ≠ 邮件正式节奏
- 英文 IM 比中文微信更直接（少客气）
- 不重复"hello" "how are you" 等开场（IM 节奏不允许）

**翻译起点**：v1.1 中文版 → 直接英译（不要走"先写英文邮件"再压缩到 IM 节奏）

## 微信对话结束后的"动作触发"

每次微信客户对话**结束后**：

| 客户状态 | 触发动作 |
|---|---|
| 客户已付 ¥49 | **立即**启动病例整理 + 给医院询单（不等伟烨） |
| 客户没付，回了"考虑一下" | 等客户，**不要追**（微信里追 = 骚扰） |
| 客户说"急" | 主动报告给伟烨："X 客户说情况急" |
| 客户发资料但没付款 | 资料**不下到本地**（合规 + 没付钱 = 没授权） |
