# 医疗旅游内容选题挖矿框架

> 来源：AI生意挖掘课程笔记（2026-04-30 伟烨分享）
> 核心原则：**不要空想创意，要从真实痛苦中挖矿**

## 五步流程

### 1. 找市场
- 让AI生成3个领域的思维导图（育儿、教育、远程办公等）
- 暴力拆解，直到能解决一个**具体麻烦**，让人一眼看懂
- 同时满足三个条件才算金矿：
  - 我有兴趣
  - 我懂行
  - 用户够疼

### 2. 验市场
- **搜索量**：Keywords Everywhere 查目标词，右侧出现长尾词=有人主动求救
- **趋势**：Google Trends 看曲线，稳步上升通道=可用；下降=抛弃
- **子领域**：搜索结果"大家还在搜"进一步挖掘有潜力的市场分类

### 3. 采数据
- 搜索社区：Google 搜索 + Reddit 限定（例：`site:reddit.com "most difficult" "help me"`）
- 筛选求救帖：找长篇大论、充满个人挣扎的帖子，不是闲聊帖
- 直接几万字原文存入记事本 = 痛苦原矿

### 4. 处理数据
- AI统计痛点频率 → 找出用户最想花钱的核心痛点
- 选定核心痛点，给出1秒能看懂的解决方案
- 生成给建站工具（Lovely等）的终极prompt

### 5. 生成落地页
- AI快速建站
- 必须有 CTA 按钮（加入候补名单/立即购买）
- 没人点 → 推倒重来

---

## 三个坑

| 坑 | 说明 |
|----|------|
| 细分不到位 | 领域必须细分到能解决一个具体麻烦，且让人1秒看懂 |
| 数据采集太浅 | 只看一两个帖子抓不住刚需，必须长篇吐槽帖 |
| 不敢卖 | 返回社区里勇敢发帖子，有反应=真正的金子 |

---

## 对医疗旅游网站的潜在应用

- 用此框架验证：来中国治病的老外最疼的是什么？
- 选题方向：不要猜，用 Reddit/Quora 真实帖子验证
- 已有内容 vs 真正有需求的：可能存在错配

**当前覆盖领域**（需验证优先级）：
- 癌症（cancer）
- 心脏（cardiac）
- IVF
- 骨科（orthopedics）
- 牙科（dental implants）

**待验证**：
- 哪些领域的搜索量在涨？
- 老外真实吐槽集中在哪些痛点？（费用？等待时间？语言？信任？）
- Reddit/Quora 上关于来中国治病的帖子在讨论什么？
