## Pitfalls (validated 2026-07-10, two CAR-T articles shipped)

### 1. JSON-LD schema MUST be a JSON ARRAY, not two adjacent objects

If frontmatter `schema:` contains `{...}{...}` (one Article + one FAQPage), Nunjucks renders them as invalid JSON (no comma, no array brackets). Google schema validator rejects.

❌ Wrong:
```yaml
schema: |
  { "@type": "Article", ... }
  { "@type": "FAQPage", ... }
```

✅ Correct:
```yaml
schema: |
  [
    { "@type": "Article", ... },
    { "@type": "FAQPage", "mainEntity": [ ... ] }
  ]
```

**Verify after every write:** extract the `<script type="application/ld+json">` block from the built HTML and parse with `json.loads()`. If it fails, the article is broken for SEO.

### 2. mainEntityOfPage URL must use 11ty pretty URL form

11ty's default permalink renders `.md` to `slug/index.html`. JSON-LD's `mainEntityOfPage.@id` must match.

❌ `"@id": "https://chinahospitalsguide.com/blog/car-t-cost-china-2026.html"`
✅ `"@id": "https://chinahospitalsguide.com/blog/car-t-cost-china-2026/"`

### 3. Local repo may lag behind master

CONTENT_GUIDE.md and `_layouts/blog-post.njk` are updated on master. Local `/home/ubuntu/chinahospitalsguide` may be 10+ commits behind. Always `git pull` first.

### 4. `blog/*.md` was historically ignored — confirm removal

Old `eleventy.config.js` had `eleventyConfig.ignores.add("blog/*.md")`. Current config should have a 2026-07-10 comment confirming removal. If `.md` files silently fail to build, check this first.

### 5. CAR-T pricing has TWO tiers — never quote just one

Per CONTENT_GUIDE.md §5:
- **Commercial NMPA-approved products**: $89K-$151K (hematologic CD19/BCMA) or $89K-$170K (satri-cel solid tumor)
- **Clinical trial / sponsored access**: $30K-$80K for eligible patients

Always state both tiers explicitly. Comparing only one tier vs US $300K-$500K is misleading.

### 6. Indonesia & Vietnam patients need M visa despite visa-free entry

Both have 30-day visa-free tourism entry as of mid-2026, but a 4-6 week CAR-T stay requires an M (medical) visa. Hospital invitation letter is the trigger document. Don't tell patients "visa-free is fine" — visit length matters.

## Article structure (CONTENT_GUIDE.md §3, §4, §8 checklist)

Each new `blog/*.md` article must include:

1. **Frontmatter**: `layout: blog-post.njk`, `title` (with cost number), `description` (≤160 chars, with price), `kicker`, `subtitle`, `date`, `schema` (Article+FAQPage array), `pageStyle` (optional)
2. **H2 sections**: ① cost comparison table (≥2 countries), ② 3-5 recommended hospitals with international dept info, ③ why-China, ④ how international patients arrange treatment, ⑤ FAQ
3. **≥2 internal links** to `/treatments/` or `/blog/`
4. **≥1 language page link** (`/ru.html` or `/ar.html`)
5. **Every cost figure** marked "2026 estimates"
6. **No fabricated stats** (no "500+ patients helped", no "98% satisfaction")


**Post-build schema validation:**
```python
import re, json
src = open(f'_site/blog/<slug>/index.html',encoding='utf-8').read()
m = re.search(r'<script type="application/ld\+json">\s*(.+?)\s*</script>', src, re.DOTALL)
parsed = json.loads(m.group(1))  # MUST succeed
assert isinstance(parsed, list) and len(parsed) >= 2
assert any(o.get('@type')=='Article' for o in parsed)
assert any(o.get('@type')=='FAQPage' for o in parsed)
```
