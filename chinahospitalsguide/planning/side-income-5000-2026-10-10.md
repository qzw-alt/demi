# 补贴型副业选型 — 月入 ¥5,000 目标

日期: 2026-10-10 · 触发: 伟烨"医疗旅游项目需要时间和成本，我在坚持，想通过额外项目补贴主力项目，想过外贸或跨境电商，有别的建议？每月 5000 左右收入就行"
前置: `fishing-tackle-export-model-2026-09-26.md`（钓具服务商模式）、`investor-or-not-2026-10-09.md`（瓶颈诊断）
级别: 建议（不替伟烨拍板；税务/主体/牌照推给持牌专业人士）

---

## 0. 一句话判断

**你要的不是"再开一个项目"，是"每月 ¥5,000 的现金流"——这两个东西的解法完全不同。**
按市场价，¥5,000/月 = **一个客户**。所以问题不是"做哪个赛道"，是"本周去找谁"。
自营开店（阿里国际站 / 亚马逊）不是补贴，是换赛道：先负 3–6 个月现金流 + 吃掉你全部时间，主力项目会被拖死。

## 2. 可迁移的原则 vs 不可照搬的赛道

**可迁移（跟市场无关）**
1. 卖"交付物"不卖"席位"——先给成果（样品页 / 逐条询盘建议），再谈签约
2. 收入结构里必须有一笔**一次性款**（建站/诊断）垫现金流，纯月费要 3 个月才回本
3. 不押自己控制不了的结果——只承诺"交付质量 + 过程指标"（上线日期、有效询盘条数），**不承诺订单金额**
4. 边际交付成本必须靠 AI 压下来（你有现成的内容流水线，别人是一堆人）

**不可照搬（市场特有死穴）**
- 自营跨境店 = 平台费 + 库存 + 广告 + 合规 + 账期，**先亏后赚**，且要全时盯 → 与你"主业不能停"直接冲突
- 平台代运营的"效果提成"在国内常被当卖点，实际是你替客户承担销售风险

## 3. 按三条硬标准排序（客单能养交付 / 结果可归因 / 你有不对称优势）

### 🥇 方向 A — 制造业出海的"英文获客"服务（工厂代运营 / 独立站）
- **客单**：¥3,000 – 12,000 / 月（+ 建站 ¥1.5 – 2.5 万一次性）
- **你的不对称优势**：chinahospitalsguide.com 本身就是一个**已上线的英文 SEO 站**，加一条 AI 内容流水线——这是别人要外包三个岗位才有的东西；且你人在威海，**钓具产业带 1,400+ 家企业**，加山东其他产业带，客户就在隔壁，可当面谈
- **到目标**：1 个客户
- **坑**
  - 海外获客 3–6 个月才起量，客户第 2 个月就会问"怎么还没单" → 合同必须写过程指标 + 阶段考核（沿用钓具前案第 5 节）
  - 你只有一个人 → **最多同时接 2–3 家**，别贪
  - 选厂标准（前案结论）：**有产能、没外贸团队、愿意给独家/尾巴条款**；已经有外贸部和常年参展的不要碰
  - 先收一次性建站费，月费后置——否则你在给客户垫现金

### 🥈 方向 B — 医院国际部 / 涉外机构的"海外患者获客"服务
- **客单**：最高（B 端预算，可人民币开票）
- **证据**：人民日报已明说医院国际部要靠外部机构"从海外找患者"；博鳌乐城已有专门公司做国际医疗团接待
- **最大价值不在钱，在反哺**：这条路的客户关系、医院通道、海外曝光，**直接喂回主力项目**
- **坑**
  - 公立采购慢（回款 3–6 个月），需发票/主体/可能的招投标
  - 医疗类内容受《医疗广告认定指南》（2025 年第 29 号公告）约束，"借科普变相发医疗广告"同样违法；**不承诺疗效、不承诺到院人数**
  - 定位为 3–6 个月的升级路径，不是本月的救命钱

### 🥉 方向 C — 海外医疗旅游中介的"中国落地"（ground handling）
- **模式**：给欧美/中东的医疗旅游中介做中国地面——医院对接、病历翻译、陪诊、行程协调。按例收费或月度 retainer
- **优势**：复用你现有的医院关系 + 现有患者流程，几乎零新增学习成本；且对方带来的患者未来可能转成你自己的客户（协同而非竞争）
- **坑**
  - **单价我没有可核实的公开数据，必须自己询价**（别拿我编的数去谈）
  - 收款通道受限（香港主体未成立）→ 现阶段只能靠现有主体的服务费口径
  - 体量有限：找 2–3 家就饱和了

### ⏱ 过桥选项 — 用英文能力直接接单（本周就能见钱）
病历翻译 / 英文润色 / 跨境 listing 优化 / 海外平台英文内容外包。
¥5,000/月 ≈ 每月 8–10 单或 1 个长期客户。
**定位：3 个月过桥，不是终局**——时薪低、不可积累、不产生资产。

### ❌ 不建议现在做 — 自营跨境电商 / 自己开店卖货
- 阿里：¥4 万起步（口径见 §1），无试用期不退；亚马逊：$39.99/月 起步看似便宜，但备货 + 广告 + 2026-04 起加收 3.5% 附加费，实际 3–8 万
- **致命点**：现金流先负 3–6 个月，且必须全时投入 → 你没有时间管医疗旅游。**这不是补贴，是换赛道**
- **例外**：如果你手上已经有确定的、有人在买的货源 + 现成买家，那可以做；否则别开

## 4. 境内合规红线（最容易被跳过的一节）

| # | 红线 | 说明 |
|---|---|---|
| 1 | **不代收代付货款**（"二清"） | 服务费走自己主体开票即可；一旦替客户收货款再转付 = 无证经营支付业务（《支付结算办法》第 6 条；《非银行支付机构监督管理条例》2026-05 全面施行） |
| 2 | **不承诺结果** | 可承诺"上线日期 / 有效询盘条数"（可归因）；**不可承诺订单、金额、到院人数、疗效** |
| 3 | 涉医疗端获客 | 《医疗广告认定指南》（市场监管总局等 2025 年第 29 号公告）+《广告法》：借科普变相发医疗广告同样违法 |
| 4 | 收款 / 主体 | 香港主体未成立 → 现阶段以现有主体收服务费；外币收款通道单独确认（见 `medical-tourism-client-intake` → `references/payment-processor-compliance-stripe-hk.md`）|
| 5 | 员工/个税/发票 | 一个自然人接多家 B 端客户，怎么开票怎么报税 |

**主体 / 税务 / 出口退税 / 关联交易由持牌会计师、律师定，本文不下结论。**
（另：若将来走"帮客户出口"路线而非纯服务，可了解**外贸综合服务企业（外综服）**代办报关/退税/收汇的合规路径——具体适用性问专业人士。）

## 5. 我的判断（一句话）

**最省事的路径是：把你已经建成的东西（英文 SEO 站 + AI 内容流水线）卖给威海/山东的工厂，1 个客户就够 ¥5,000/月；同时把医院国际部作为 3–6 个月后的升级方向——因为它反哺主业，而不是分走主业的时间。**
不要同时开两条：先跑通 1 个客户再谈第二个。

## 6. 下一步（本周可做，成本≈0）

**先测需求，不要先建产品**：找 3 家本地工厂（钓具/家纺/五金/机械），只问两个问题——
1. "你们现在海外客户从哪来？"
2. "如果有人帮你做英文内容和海外搜索曝光，按月付费，你能接受多少？"
聊完再决定做不做、怎么报价。**没被拒过 3 次之前，不要投任何钱。**
