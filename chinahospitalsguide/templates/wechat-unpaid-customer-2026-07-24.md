# 微信回复模板：未付款客户直接加微信咨询（带资料）

> **使用场景**：客户未走官网付费流程，直接加微信发病例资料。
> **核心理由**：跟医生沟通涉及**医生成本 + 人力成本 + 医院对接成本**，必须先收费才启动。
> **目的**：把"收费"包装成"我们的成本结构决定" —— 不是"我们想赚你钱"，是"你不付钱我们没法启动服务"。

---

## 回复原则（沟通底线）

1. **不冷漠**：先承认客户主动找我们（这本身是信任）
2. **理由是"成本"不是"流程"**：客户更容易接受"成本决定要先付"（中性、客观），而不是"流程规定要付"（听起来官僚）
3. **把"收费"框成"启动服务"**：不付钱 = 没启动 = 没服务；付钱 = 启动 = 拿到东西
4. **承认客户急**：留一个出口（紧急情况可优先，但要先付）
5. **不发长段**：1-2 句 / 条

---

## 微信消息模板（5 条 · 1-2 句 / 条）

> 复制到微信对话时按"消息 1 → 消息 2 → ... → 消息 5"顺序，每条单独发。

### 消息 1：感谢 + 接住情绪
```
您好，看到您发的资料了。先说一句：您愿意主动找我们，我们很感谢这份信任。
```

### 消息 2：说明成本结构（核心 · 不强势）
```
我得先跟您把话说清楚——跟医院、医生沟通，是要付出成本的。
医生那边有医生的时间成本，我们这边有人力协调成本，
跟医院正式对接还有医院的接洽成本。这三块加起来，
不是免费能撑得起的。
```

### 消息 3：把"收费"框成"启动服务"
```
所以我们这边需要先启动费用，才会让医生介入。
第一步是 ¥49 初步咨询——包括病例整理 + 2-3 家最适合您的
医院推荐 + 全程费用预估。付完这个，我们才会正式跟
医院/医生联系。
```

### 消息 4：行动引导（轻 CTA）
```
您可以看下我们的套餐说明：https://chinahospitalsguide.com/pricing.html
或者直接告诉我您大概在什么阶段（刚确诊？已经看过几家医院？
想找海外？），我帮您看看 ¥49 套餐对您合不合适。
```

### 消息 5（可选 · 仅在客户说"很急"时发）
```
如果情况比较急 / 已经在国内其他医院看过想转诊，
告诉我具体情况，您先付 ¥49，我们走优先通道马上启动。
```

---

## ❌ 不要做的事

- ❌ **不要先回复具体医疗问题**（"您的肺癌应该是 X 期"）
- ❌ **不要承诺"看了您资料再说"**（隐含免费咨询）
- ❌ **不要在没付款前约视频 / 电话**（破坏规则）
- ❌ **不要长篇大论**（客户耐心低，5 段以内）
- ❌ **不要用"流程规定"作为理由**（听起来官僚；用"成本结构"替代）

---

## ✅ 如果客户问"那 ¥49 包含什么 / 不包含什么？"

回这一句就够：
> "¥49 包含：病例整理 + 2-3 家医院推荐 + 全程费用预估。不包含：医生直接沟通（那是 ¥399 协调套餐里）。如果 ¥49 做完您觉得合适，再决定 ¥399 是否启动。"

**核心**：让客户看到 ¥49 是"低风险"——付了不亏，不合适能停。

---

## ✅ 如果客户反问"看了你网站，没付款你们也会给建议吧？"

回这一句：
> "网站上公开的内容是给所有人看的通用信息。但您这种情况——具体看您的资料 + 联系具体医院 + 让医生介入——这三件事都是要成本的，¥49 就是启动这个的成本。"

---

## ✅ 如果客户说"我先付 ¥49 但不一定要继续 ¥399"

回这一句（让他安心）：
> "完全可以。¥49 是独立服务，做完您拿到报告，自己决定下一步。我们不会催您继续 ¥399，也不会因为您不继续就降级服务。"

**核心**：消除客户"被锁定"焦虑。

---

## 🔁 复用规则

**每次客户加微信发资料**，按这 5 条**顺序发**。**最常见的变体**：
- 如果客户没发资料只问"你们能治癌吗" → **省掉消息 1**（没有"看到您资料"）
- 如果客户说"钱不是问题" → **消息 3 改成 ¥399 套餐**（不引导 ¥49）
- 如果客户是 Maria 这种"已签 case sharing 客户" → 不用这模板
